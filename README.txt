[使用方法]
1. 新建 Minecraft 1.21.1 + NeoForge 21.1.x 实例。
2. 首次启动让 NeoForge 初始化，然后关闭游戏。
3. 将 mods 与 shaderpacks 复制进实例对应目录。
4. 同步 config 与 kubejs；启动后在光影设置中选择 Complementary。

[建空岛世界]
新建世界 → 更多世界选项 → 世界类型选择 Skyblock（Skyblock Builder），直接生成。
